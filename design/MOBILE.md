# 모바일 레이아웃 설계 (작업 예정)

> 2026-08-14 착수 대기. 로컬 작업만 하고 **푸시하지 않는다.**
> 완료 후 Pen 캔버스(`design/_pen/src/game-decider.pen`)에도 반영한다.

## 지금 뭐가 문제인가

데스크톱 LNB(`aside.lnb`, 260px 고정)를 모바일에서 **상단으로 접기만** 했다.
그 결과 첫 화면 상단에 서비스명 · 프로필 · 탭 2줄 · 언어 전환 · 로그아웃이
전부 쌓여, 스크롤 없이는 콘텐츠가 시작되지도 않는다.
데스크톱 구조를 좁힌 게 아니라 **모바일 구조를 따로 잡아야 한다.**

관련 코드: `styles.css` 의 `@media (max-width: 900px)` 블록,
`index.html` 의 `aside.lnb`.

## 방향

### 1. 내비게이션을 하단 탭 바로
- 상단은 **타이틀 한 줄**만 (로고 + 현재 화면 이름 + 우측 아이콘 1개).
- 이동은 하단 고정 탭 4개: 오늘의 도전 / 이어하기 / 내 게임 / 도전과제.
  - '친구랑'은 5번째 탭이 아니라 '더보기' 또는 내 게임 안으로.
    엄지 도달 범위에 4개가 한계다.
- `env(safe-area-inset-bottom)` 반영 (iOS 홈 인디케이터).

### 2. 프로필·언어·로그아웃은 숨긴다
매 화면에 있을 이유가 없다. 상단 우측 아바타를 눌러 여는
시트(bottom sheet) 하나로 모은다: 프로필 · 동기화 상태 · 언어 · 로그아웃.

### 3. 화면별
| 화면 | 모바일에서 |
|---|---|
| 오늘의 도전 | 카드 3장 가로 스와이프(스냅). 세로로 쌓으면 3스크롤이 된다 |
| 이어하기 | 커버를 카드 상단 전체 폭으로. 좌우 분할은 좁아서 둘 다 죽는다 |
| 내 게임 | 2열 그리드. 정렬 버튼 바는 가로 스크롤 |
| 도전과제 | 서브탭 유지, 등급 타일은 가로 스크롤 |
| 게임 상세 | 지표 스트립 2×2, 도전과제 달성/미달성은 컬럼→탭 전환 |
| 친구랑 | 1열 |
| 로그인 | 이미 세로 중앙 정렬이라 큰 손 안 대도 됨 |

### 4. 지킬 것
- **터치 타깃 44px 이상.** 지금 `.sort-btn`(40px)·`.nav-item` 이 미달.
- 가로 스크롤 영역은 스크롤바를 숨기되 **끝에 페이드**로 더 있음을 알린다.
- 이미지 비율은 데스크톱과 동일하게 원본 유지 (`aspect-ratio` + `contain`).
  좁다고 `cover` 로 바꾸면 또 잘린다.
- 로딩 스켈레톤도 모바일 레이아웃에 맞춰 개수·모양을 바꾼다.

## 검증
- 폭 **390px(iPhone 14)** · **360px(안드로이드 최빈)** 두 지점에서 계산값 확인.
- 캡처 모드로 Pen 에 임포트: `?w=390&h=844`.
  (데스크톱 프레임은 1920 폭 그대로 두고 **모바일 프레임을 따로** 만든다)
